# SCM Logistics Analysis Project 

## Project Overview
This project analyzes delivery performance and profitability for the European electronics market using a multi-stage data pipeline.

## Tech Stack
- **SQL (SQLite):** Data extraction & mart construction.
- **Python (Pandas):** Business logic implementation & risk labeling.
- **Power BI:** Interactive dashboarding & KPI tracking (OTD Rate).

## Key Insights
- **Standard Class Performance:** Identified significant negative delays, suggesting conservative scheduling.
- **Bottleneck Identification:** Pinpointed high-latency nodes in specific cities using geospatial mapping.
- **Financial Impact:** Correlated delivery delays with profit margins to identify high-risk routes.
